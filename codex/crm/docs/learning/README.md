这些教程不是脱离仓库的语言百科，而是帮助初学者在真实 CRM 代码中形成“能读、能改、能测、能发布”的能力。

## Web 前端学习路线

按以下顺序从语言基础走到真实交付：

```text
JavaScript 运行时与浏览器
-> TypeScript 类型与 API 契约
-> HTML/CSS 结构、布局与可访问性
-> React 组件、状态、Effect 与异步竞态
-> Vite/Ant Design/联调/测试/安全/发布
-> 在 frontend/ 完成一个小型分页管理页
```

每篇都包含基础、进阶、项目场景和完成标准。已有前端经验可先读 [前端工程化](FRONTEND_ENGINEERING.md)，再按薄弱点回补专题；实际开发规范以 [Web 管理台手册](../manuals/FRONTEND.md) 为准。

## 学习方法

每个知识点按五步练习：

1. 读“为什么”：理解概念解决的具体问题。
2. 找“在哪里”：用给出的仓库路径定位真实代码。
3. 画“怎样流动”：从输入追到输出，不急着改。
4. 做“小改动”：只修改一个可验证行为。
5. 用命令验收：构建、测试、接口或设备操作证明结果。

学习练习默认只建议在独立分支和本地/测试环境操作。涉及删除、生产数据库、第三方凭据或商店发布的步骤不能作为练习直接执行。

## 推荐顺序

```text
基础语法/平台 -> 读项目入口 -> 跟一次登录请求 -> 跟一次列表请求
-> 修改一个只读字段 -> 补测试 -> 跑构建 -> 做端到端验证
-> 学配置/并发/安全 -> 理解发布与回滚
```

## 完成标准

学习者应能独立回答：

- 这个功能属于哪个项目和模块？
- 请求、Token、数据和错误经过哪些层？
- 变更会影响哪个数据库、客户端和发布步骤？
- 最小测试是什么，怎样证明没有破坏其他模块？
- 故障时先看哪个日志/状态，而不是盲目改代码？
- 哪些密钥、数据和破坏性操作不能提交或直接执行？

掌握以上问题后，再按 [开发手册总览](../manuals/README.md) 进入真实需求。
